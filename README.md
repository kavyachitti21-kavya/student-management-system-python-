# 🎓 Student Management System

## 📌 Description

The **Student Management System** is a simple application developed to manage student records efficiently. It allows users to add, view, search, update, and delete student information. This project demonstrates the basic concepts of programming, data management, and CRUD (Create, Read, Update, Delete) operations.

---

## ✨ Features

* ➕ Add new student records
* 📋 View all students
* 🔍 Search students by Roll Number
* ✏️ Update student details
* ❌ Delete student records
* 🖥️ User-friendly console interface

## 🚀 Getting Started

### Prerequisites

* Python 3.x installed on your computer

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/Student-Management-System.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Student-Management-System
   ```

3. Run the program:

   ```bash
   python student_management.py
   ```

---

## 📖 Usage

1. Run the application.
2. Choose an option from the menu.
3. Add, view, search, update, or delete student records.
4. Exit the application when finished.
